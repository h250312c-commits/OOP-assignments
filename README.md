# Assignment Title: Bank Account Management System Using Java

## Project Overview
This Java project demonstrates core Object-Oriented Programming principles in the design of a simple bank account management system. It defines a reusable abstract `Account` class that stores essential account information and implements common operations such as deposit validation and balance retrieval.

## Objectives
- Model a bank account using Java classes
- Apply encapsulation and abstraction
- Validate account creation and deposit operations
- Provide a base structure for future account types such as savings and current accounts

## Features
- Ensures the account number is not blank
- Prevents negative initial balances
- Rejects non-positive deposit amounts
- Tracks the current account balance
- Declares abstract methods for withdrawal and monthly processing

## File Structure
- `Account.java` - Base abstract account class containing account number, balance, deposit logic, and abstract methods
